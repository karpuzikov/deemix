# Deemix core continuity

Purpose: TypeScript Deezer download engine, queue/download behavior, track metadata, MusicBrainz / LRCLIB fallbacks, Spotify and ListenBrainz plugins.
Version: 3.14.0. Source: packages/deemix/src; tests: packages/deemix/src/**/*.test.ts. Data: OS config folder (APPDATA/deemix on Windows unless DEEMIX_DATA_DIR set), persisted queues/settings/caches and login. Music output getMusicFolder or DEEMIX_MUSIC_DIR.

Critical behavior: keep requested release UPC/title/track listing when Deezer gateway redirects playback; only main-artist albums in full discography; preserve distinct UPC editions; use ISRC exact matching before substituting tracks; respect bitrate license and download fallback settings. ## v0.5.4 - Under construction ⚠️: optional clean/explicit duplicate filtering (2026-10-09)

Feature: **Settings > Downloads > Skip clean version if explicit is available**. `skipCleanIfExplicitAvailable` is a persisted `Settings` boolean, default `false` and automatically inserted into existing `config.json` by settings migration. In `DeemixApp.addToQueue`, gather full candidate release batch (artist discography, multi-link requests), then use `skipCleanWhenExplicitAvailable` from `packages/deemix/src/download-objects/releaseVariants.ts` before writing queue items. Candidate comparison demands known clean metadata, positive explicit metadata in another generated candidate, equivalent normalized artist, album title (only Clean/Explicit markers stripped), complete ordered track titles and count.
